# いごドリル

幼児〜小学生向けの、囲碁入門アプリです。
ひらがな中心・大きな文字で、スマホの縦画面に合わせて作っています。
HTMLファイル1つだけで動き、外部ライブラリやサーバーは使っていません。

## できること

### 📖 ルールの せつめい（11ステップ）

| | ステップ | 内容 |
|---|---|---|
| ① | いしの おきかた | 線の交わるところに置く |
| ② | いしの とりかた | あき（ダメ）を全部ふさぐと取れる・アタリ |
| ③ | にげる | アタリから伸びて逃げる |
| ④ | おけない ところ | 着手禁止点と「取れるときは置ける」例外 |
| ⑤ | つなぐ・きる | 石のつながりと切断 |
| ⑥ | 「め」とは なにか | 目の考え方 |
| ⑦ | いきている いし | 目が2つあると取られない |
| ⑧ | かけめ | 目に見えて目ではない形 |
| ⑨ | いろんな いきの かたち | まっすぐ・曲がった・離れた形 |
| ⑩ | こう | すぐには取り返せないルール |
| ⑪ | おわりと かちまけ | 陣地の広いほうが勝ち |

- 各ステップには、石を置いて試せる小さな盤のデモが付いています。
- 各ステップの最後に「たしかめ もんだい」が1問あり、正解すると読んだ印が付きます。

### 🧩 ドリル（6テーマ × 10問 = 60問）

とる／にげる／りょうあたり／しちょう・げた／つなぐ・きる／「め」を つくる

- **間違えたとき**：理由を表示します。たとえば、相手の石のあきを●で示して「まだ あきが ○つ あるね」と出します。
- **ヒント**：「文章 → 赤い丸 → 答え」の3段階で出せます。
- **記録の印**：自分で解けた問題は ⭐、答えを見て解いた問題は 💡 です。
- **しちょう・げた**：白は自動で逃げます。白のどの逃げ方にも取り切れる手を、正解にしています。

### そのほか

- 盤を押すと、その場で石が置かれます（1回押し）。
- 🔊ボタンで画面の文章を読み上げます。ブラウザの音声合成を使うため、端末によっては声が出ません。
- 正解すると、効果音と簡単な演出が出ます。
- 問題やステップは、スマホの縦画面1枚にスクロールなしで収まるよう、盤の大きさを自動で調整します。

## 使い方

1. `index.html` をブラウザで開きます。公開後はGitHub PagesのURLから開けます。
2. トップ画面から「るーるの せつめい」か、ドリルのテーマを選びます。
3. 盤の上の、石を置きたいところを押します。

## 記録の保存について

- 進み具合は、使っているブラウザの中（localStorage）だけに保存します。
- サーバーには何も送りません。名前などの個人情報も集めていません。
- 別の端末やブラウザとは、記録は共有されません。
- トップ画面の「きろくを けす」で消せます。

## 問題の追加・変更

問題のデータは、`index.html` の中のJavaScriptに配列で書いてあります。

| 追加したいもの | 書く場所 | 補足 |
|---|---|---|
| 「とる」の問題 | `CAPTURE` 配列に1問足す | |
| ほかのテーマの問題 | `BASES` のテーマ別配列に、もとの形を1つ足す | 回転・反転した問題を自動で作り、各テーマ10問にそろえます |
| ルールの説明・確認問題 | `RULES` 配列 | |

- 座標は `[よこ, たて]` で、左上が `[0,0]`、9路盤の右下が `[8,8]` です。
- ヒントの文章には「うえ・した」などの向きの言葉を使わないでください。回転した問題でも意味が通るようにするためです。
